# Patrick Delfino

Desenvolvedor Full Stack com mais de sete anos de experiência profissional. Trabalho com PHP, JavaScript, SQL e APIs REST no desenvolvimento de aplicações web, da interface e do banco de dados à implantação e à manutenção em produção.

Na Sarthemes, de setembro de 2018 a setembro de 2025, desenvolvi plataformas de streaming, sistemas de gestão de conteúdo, portais de produtos financeiros e lojas virtuais. Também atuei com servidores Linux, integrações, cache e desempenho web.
